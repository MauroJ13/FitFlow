## Decisions (do not re-decide)
- Stack: React 19 + TypeScript + Vite 6 + SCSS, HashRouter (works on any static host), Recharts, Supabase, lucide-react, pdfjs-dist, tesseract.js.
- Local-first: every table lives in IndexedDB (`src/lib/db.ts`), mirrored in memory; `src/lib/sync.ts` pushes dirty rows (upsert by client-generated id) and pulls by `synced_at` cursor; deletes are tombstones (`deleted = true`); last write wins via `updated_at` (server trigger rejects stale writes).
- Without `.env` Supabase values the app runs in local-only mode (no account).
- i18n: own tiny system in `src/i18n` (flat keys, `en.ts` is the source; `de.ts`, `hr.ts` must have the same keys – check with `npm run check:i18n`). Default language: English.
- AI (session 3, user decision): SAME approach as the user's LinguaAI project (`~/Documents/VS Code Dokus/LinguaAI/src/services/ai/freeProviders.ts`): free keyless OpenAI-compatible services called from the browser – OVHcloud AI Endpoints (Mistral-Small-3.2, Qwen3.5-397B, gpt-oss-120b; 2 req/min/model anonymous) + LLM7.io (DeepSeek-V4-Flash, gpt-oss:20b, mistral-Nemo). Code: `src/lib/aiProviders.ts` (rotation, rate tracking, blocking), `src/lib/ai.ts` (prompts, context, tasks, plan suggestion). NO Llama, NO Groq, NO user key, NO setup, NO backend. No scripted fallback answers – honest error messages (`ai.err_*`). User can switch AI off (`prefs.ai.enabled`) and choose shared categories. All numbers computed by the app; AI only writes text. The old Supabase function `fitflow-ai` was removed.
- No calorie targets / no streak punishment / no invented measurements (spec requirement).
- PWA: hand-written service worker generated by a small plugin in `vite.config.ts` from `pwa/sw.template.js` (no vite-plugin-pwa).
- SCSS rule: plain nesting only, no `&-suffix` concatenation, only the `desktop` mixin – this lets `scripts/smoke` render the styles without the sass package.
- `npm run build` = `vite build` (type errors do not block); `npm run typecheck` = `tsc --noEmit`.
